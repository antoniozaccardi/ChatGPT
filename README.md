# ChatGPT

Dépôt de démarrage pour travailler sur des projets avec Codex.

## Démarrer avec Codex

1. Ouvrez Codex dans ChatGPT.
2. Connectez ce dépôt GitHub à un environnement Codex Cloud.
3. Décrivez la première tâche à réaliser dans le dépôt.

Ce dépôt est prêt à recevoir le code du projet que vous choisirez de créer.
